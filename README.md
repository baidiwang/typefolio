# typefolio

Baidi Wang — Design Engineer portfolio (typewriter / letter concept).

## Concept · 概念

**EN:** A light cream “paper letter” single-page portfolio. Letterhead stays visible; featured projects expand in-place. A typewriter animation at the bottom is planned later — **not** in this skeleton.

**中文：** 浅奶油色「纸质信件」单页作品集。页眉始终可见；精选项目就地展开。底部打字机动画稍后加入——当前仅为静态骨架。

## Run · 运行

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Edit content · 编辑文案

All site copy lives in [`src/content.ts`](src/content.ts). Update project blurbs, links (email / LinkedIn / resume), and TODOs there.

## Stack

Vite + React + TypeScript. Simple CSS in `src/index.css` (accessible focus, reduced motion).
